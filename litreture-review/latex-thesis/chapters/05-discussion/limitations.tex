\section{Limitations}
\label{sec:limitations}

\begin{itemize}
  \item Local infrastructure (Kind, Multipass) does not replicate cloud-specific behaviours such as network latency between nodes, cloud disk I/O performance, or managed control plane characteristics.
  \item Synthetic workloads may not capture all real-world pipeline behaviour patterns.
  \item Single physical host means the Kind cluster cannot demonstrate true multi-node scaling.
  \item Three repetitions provide directional findings, not statistically significant effects.
  \item Dagster as representative system---other workflow frameworks may behave differently.
  \item If GCP validation was not performed, cloud-specific crossover may differ.
\end{itemize}
