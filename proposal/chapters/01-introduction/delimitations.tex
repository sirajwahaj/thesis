\section{Delimitations}

This study does not include:

\begin{itemize}
  \item Cloud-hosted Kubernetes (no \textsc{gcp}/\textsc{aws}/Azure costs)
  \item Comparison between orchestration tools --- the focus is on execution model
        behaviour, not tool selection
  \item \textsc{ml} model accuracy evaluation
  \item Alternative \vm{} executor configurations --- only the DockerRunLauncher is used;
        the legacy ProcessExecutor is explicitly excluded
  \item Real or sensitive data --- synthetic workloads only
  \item Autoscaling experiments --- the Kind cluster is single-node with fixed resources,
        which eliminates node-level scaling and allows isolation of overhead and contention
        effects
\end{itemize}
