# LaTeX Thesis Conventions

## Canonical source

- **`docs/chapters/`** is canonical — this is what gets compiled into the thesis PDF
- **`proposal/`** is stale (original expanded proposal) — never edit it
- **`litreture-review/latex-thesis/`** is stale — never edit it
- Root document: `docs/main.tex` — do not restructure it

## Chapter structure

```
docs/chapters/0N-name/
├── main.tex          ← hub file, uses \input{} for each section
├── section-a.tex
└── section-b.tex
```

- One `.tex` file per section
- Hub files use `\input{}`, not `\include{}` (no page break between sections)
- Chapter 4 (`04-results/`) — only fill in after experiments are complete; do not hardcode values

## Exact metric names — use these and only these

These must match `docs/chapters/03-method/metrics.tex` exactly:

| Use this | Not this |
|----------|----------|
| `job success rate` | "success rate", "completion rate", "pass rate" |
| `execution time variance` | "variance", "std dev", "standard deviation" |
| `mean execution time` | "average execution time", "avg time" |
| `pod scheduling latency` | "scheduling time", "schedule latency", "K8s latency" |
| `container startup time` | "startup time", "container boot", "init time" |
| `failure blast radius` | "blast radius", "error propagation" |
| `crossover point` | "break-even", "inflection point", "tipping point" |
| `net execution time delta` | "time difference", "overhead delta" |

## Figures workflow

All figures are generated by `notebooks/analysis.ipynb` and follow this pipeline:
```
analysis.ipynb → results/*.png → make copy-figures → docs/figures/*.png
```

- **Never add static images manually** to `docs/figures/`
- Reference in LaTeX: `\includegraphics{figures/<filename>.png}`
- Naming convention: `exp{N}_{metric_name}.png` (e.g., `exp1_success_rate.png`)

```latex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.9\textwidth]{figures/exp1_success_rate.png}
  \caption{Job success rate across concurrency levels, VM environment (Experiment 1).
           Each point is the mean of 3 repetitions; error bars show ±1 standard deviation.}
  \label{fig:exp1-success-rate}
\end{figure}
```

## Build

- Run `make pdf` to compile
- Requires `latexmk` and `pdflatex` — do not use `xelatex` or `lualatex`
- Output: `docs/thesis.pdf`
