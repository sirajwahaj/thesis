\section{Delimitations}
\label{sec:delimitations}

This study does not include:

\begin{itemize}
  \item Comparison between cloud providers (AWS EKS, Azure AKS)
  \item Comparison between orchestration tools---the focus is on execution model behaviour, not tool selection
  \item ML model accuracy evaluation
  \item Alternative VM executor configurations---only the DockerRunLauncher (single-VM Docker executor) is used; the legacy ProcessExecutor is explicitly excluded
  \item Real or sensitive data---synthetic workloads only
  \item Production-grade multi-node Kubernetes configurations (unless GCP budget permits the optional cloud validation)
\end{itemize}

\paragraph{Ethical statement.}
This study uses only synthetic workloads. No personal, sensitive, or proprietary data is collected or processed at any stage.
