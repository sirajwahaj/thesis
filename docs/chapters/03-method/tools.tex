\section{Tool Stack}
\label{sec:tools}

The following tools are required to execute this thesis. All are open source or freely available.

\subsection{Infrastructure Tools}
\label{subsec:infra-tools}

\begin{table}[H]
  \centering
  \caption{Infrastructure tools used in this thesis.}
  \label{tab:infra-tools}
  \small
  \begin{tabularx}{\textwidth}{llX}
    \toprule
    \textbf{Tool} & \textbf{Version} & \textbf{Purpose} \\
    \midrule
    podman              & Latest stable   & Container runtime on macOS host --- builds images, runs local docker-compose dev stack \\
    Docker CE           & Latest stable   & Container runtime on Ubuntu VM --- DockerRunLauncher dispatches each Dagster job as a container \\
    Kind            & v0.20+          & Local Kubernetes cluster for comparison environment (uses OCI images from local podman registry) \\
    UTM + Ansible   & Latest stable   & Ubuntu 22.04 VM provisioning with automated Docker CE, PostgreSQL, and Dagster installation \\
    Helm            & v3.x            & Package manager for deploying Dagster on Kubernetes \\
    kubectl         & Matching K8s    & Kubernetes CLI for cluster management and pod inspection \\
    \bottomrule
  \end{tabularx}
\end{table}
